# Code of conduct

Be kind, assume good intent, and keep discussion about the code.

Harassment, personal attacks and discriminatory language aren't tolerated in issues,
pull requests or reviews. Maintainers may edit or remove such content and block those
responsible.

Report a problem privately to the maintainer through
[GitHub's security advisories](https://github.com/MiguelAPerez/HighlightBoba/security/advisories/new)
if it can't be raised in public.
