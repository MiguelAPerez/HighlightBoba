# Security policy

HighlightBoba reads untrusted text (any file a user opens), so a crash, hang or
super-linear slowdown on some input counts as a security issue.

## Reporting

Report privately through [GitHub's security advisories](https://github.com/MiguelAPerez/HighlightBoba/security/advisories/new),
not as a public issue. Include the smallest input that reproduces it and the version.
Expect a first reply within a week.

## Supported versions

Only the latest release gets fixes.
